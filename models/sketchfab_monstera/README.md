# Monstera Deliciosa Potted Mid-Century plant — Godot-ready

Original Sketchfab model by **Giora**: https://sketchfab.com/3d-models/monstera-deliciosa-potted-mid-century-plant-1ab9bf841df04c07b1819be596327629
License: **CC BY 4.0**; see bundled `license.txt`.

This optimized glTF retains all four original meshes (foliage, stalks, pot and stand),
the source geometry and UVs, and the three original physically based materials
with all nine texture assignments. The 4K texture images are resized to 256–1024px
for realtime use, with the leaves' RGBA alpha mask retained.

The glTF root includes the original orientation and centimeter-to-meter scaling
(transform hierarchy preserved). Place in `res://models/sketchfab_monstera/`.
