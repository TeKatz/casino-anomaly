# The Silent Audience – third-party assets

These five user-selected Sketchfab characters are redistributed in optimized form. Textures were downscaled/recompressed; for *Realistic Female*, unused morph targets/source animation were stripped to reduce memory consumption. The skinned meshes and skeleton remain intact.
The *Realistic Female* adapted asset remains licensed under **CC BY-SA 4.0**. This does not change the license of independently authored game code.
