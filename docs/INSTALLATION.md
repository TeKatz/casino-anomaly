# Installation — Development Edition

Download the current Windows ZIP from the [Development release](https://github.com/TeKatz/casino-anomaly/releases/tag/development).
Extract the complete archive to a writable folder and launch
`CasinoAnomaly.exe`. Keep the companion PCK and bundled updater in the
same distribution. Updates can be installed from the main menu.

For the Godot source project, see [Repository structure](REPOSITORY_LAYOUT.md)
and [CI and asset preparation](CI.md). Historical model-pack instructions
are in the archive and are not required to play the Windows release.
